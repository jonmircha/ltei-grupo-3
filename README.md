# Mi Landing de CV · Jonathan MirCha

Proyecto de una **landing de CV (one-page)** de **Jonathan MirCha**. Consiste en una página web responsiva, mobile-first, construida con **HTML, CSS y JavaScript vanilla**, que presenta mi perfil profesional: quién soy, educación, experiencia, habilidades, cursos y datos de contacto.

El aspecto visual se rige por mi propio **sistema de diseño** (`DESIGN.md`), del cual se derivan las variables CSS (colores, tipografía, espaciado, formas y elevación). La arquitectura de información y el contenido se describen en `CV.md`.
